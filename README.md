JUMP! 
It is a 3d platformer game where you collect stars

<img width="172" height="100" alt="image" src="https://github.com/user-attachments/assets/5bf20468-5137-47b4-a405-044e944ad89e" />

Try it here: https://patcha123.itch.io/jump

1. The controls are WASD and space for jump and shift for sprint
2. There is a view bob to mimic real footsteps
3. the game is first person

Interesting Technical choice: I chose to use Godot for this 3d Game instead of more commonly used game engines like Unreal or Unity This is because I am already familiar with Godot and I wanted to see how it would run a 3d game.

Credits: I used Kenny's Platformer Pack for all my textures and the background for the win and start screen is a image from Google.
